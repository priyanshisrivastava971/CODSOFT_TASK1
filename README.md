# CodSoft Internship – Task 1

## Advanced Rule-Based Chatbot Using Python

### Project Description
This project is developed as part of the CodSoft Python Programming Internship.

The chatbot is built using Python and Gradio. It provides responses to user messages based on predefined rules, keyword matching and pattern recognition.

### Features
- Interactive ChatGPT-style web interface
- Greeting and farewell responses
- Date and time detection
- Basic mathematical calculations
- Study and career guidance
- Rule-based conversation
- Unknown query handling

### Technologies Used
- Python
- Gradio
- Regular Expressions (re)
- Random module
- DateTime module

### How to Run

1. Install the required library:

   `pip install gradio`

2. Run the Python chatbot program.
3. Open the Gradio interface.
4. Start chatting with the chatbot.
